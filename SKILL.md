# Skill: Patiotuerca Mobile UI

## 1. Referencia visual

Sitio: https://ecuador.patiotuerca.com/

Diseñar la interfaz móvil siguiendo la identidad visual de Patiotuerca: minimalista, moderna, comercial y orientada al sector automotriz.

## 2. Paleta de colores

Colores aproximados de referencia:

| Elemento | Color |
|----------|-------|
| Primario | #E30613 |
| Primario oscuro | #B80012 |
| Fondo principal | #FFFFFF |
| Fondo secundario | #F5F5F5 |
| Texto principal | #242424 |
| Texto secundario | #737373 |
| Bordes | #E4E4E7 |

- Predominarán los fondos blancos.
- El rojo destacará acciones y elementos activos.
- Utilizar grises para bordes y textos secundarios.

## 3. Tipografía

Fuente recomendada: Roboto o sans-serif equivalente.

- Títulos principales: 24px, bold.
- Subtítulos: 18px, semibold.
- Texto general: 14px, regular.
- Precios: 22px, bold.
- Botones: 15px, semibold.

Mantener una jerarquía clara y tipografía consistente.

## 4. Botones

### Primarios
- Fondo rojo (#E30613).
- Texto blanco.
- Bordes redondeados de 8px.
- Altura de 48px.

### Secundarios
- Fondo blanco.
- Borde gris claro.
- Texto oscuro.
- Bordes redondeados de 8px.

Evitar sombras exageradas y efectos decorativos.

## 5. Tarjetas

- Fondo blanco.
- Bordes redondeados de 12px.
- Bordes grises o sombras sutiles.
- Padding interno de 12px a 16px.
- Imágenes grandes con proporción 16:9.
- Títulos oscuros y destacados.
- Precios en negrita.
- Información secundaria en gris.
- Separación uniforme entre tarjetas.

## 6. Estilo general

- Diseño limpio, moderno y minimalista.
- Márgenes horizontales de 16px.
- Espaciado entre elementos de 8px a 16px.
- Separación entre secciones de 24px.
- Iconografía lineal y sencilla.
- Campos de búsqueda blancos con bordes grises.
- Navegación con elementos activos en rojo.
- Diseño adaptable a diferentes pantallas móviles.

## 7. Reglas para la IA

- Aplicar únicamente cambios relacionados con la interfaz visual.
- Mantener la identidad visual de Patiotuerca.
- Reutilizar colores, tipografías, botones y tarjetas.
- Priorizar consistencia visual y legibilidad.
- No modificar lógica, funcionalidades ni arquitectura.
- No añadir componentes o estilos ajenos a la referencia.
- Adaptar el diseño web a dispositivos móviles sin copiarlo literalmente.
